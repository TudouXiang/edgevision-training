# 验收方案与证据等级

本轮架构验收与未来业务验收分开。每项记录「通过 / 失败 / 未执行」，并保留命令、退出码、原始输出、代码版本与时间。界面截图只证明显示，不证明后台训练或 NPU 推理。

| ID | 条件与动作 | 必须观察到的结果 | 最低证据 |
| --- | --- | --- | --- |
| A0 | 空 DB 执行 `alembic upgrade head` 两次，启动 API/Worker | 表/约束和版本正确；第二次幂等；健康/就绪区别；第二 Worker 拒绝启动 | 迁移输出、SQLite 表和版本、HTTP 响应、进程退出码 |
| A1 | 建管理员/用户、登录/退出；猜测别人的项目 ID | 会话绑定真实角色；普通用户仅可见己方；登出/禁用失效；跨用户返回 404 | API 集成测试和实际请求记录 |
| A2 | 导入有效及有 `../`、软链接、异常标签、压缩炸弹的 ZIP | 有效导入快照/哈希及报告；危险输入拒绝且无法写出根目录 | 原始样本指纹、报告、受控目录差异 |

| A5 | 断开事件连接、页面刷新、重接 | 可按 seq 补齐、去重；终态与 GET 快照一致 | SSE 帧、断开/重接序号、页面录屏或快照 |
