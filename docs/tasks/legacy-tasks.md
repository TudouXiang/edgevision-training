# 可逐个领取的实现任务（DeepSeek / GPT5.6）

领取方法：一次一个 ID。先读 AGENTS.md 与 `feature-delivery`，提交仅该任务的改动和证据；若触及状态机、范围、技术栈或既有前端技术路线，先执行 `arch-spec`。以下测试/实验命令是**未来验收计划**，不是本轮已执行。

## T0 骨架补证与环境接管

输入：本仓库、`environment.md`、`status.md`。输出：在目标开发机安装项目局部依赖、执行 Alembic/Worker/API/前端构建，并记录命令版本和退出码；保留已有原型 ZIP，不直接上线。验收：A0、A9 的骨架部分；API 的 501 不能变成功。阻塞：实际目标机器、Python 包源/依赖下载权限。建议 `cd backend && uv sync --extra dev && uv run alembic upgrade head && uv run pytest`、`cd web && npm ci && npm run build`；记录在 `docs/evidence/T0-*.md`。

## T1 身份与双角色（依赖 T0）

输入：users/sessions 表与 `/auth`、`/admin/users` 契约。实现显式 CLI 创建首个管理员、Argon2id 密码验证、随机会话 token 的哈希存储、HttpOnly cookie、CSRF、失效/登出/禁用与管理员创建用户；前端替换“访客”态为真实身份，管理员导航仅凭服务端授权显示。不得默认账户或前端角色切换。验收 A1：匿名 401、普通用户管理端 403、失效会话 401、跨用户 404；提交集成测试与真实请求证据。

## T2 项目闭环（依赖 T1）

输入：projects 表、列表/详情/修改契约。实现 owner 过滤、管理员全局权限、搜索分页、归档/删除限制；将工作台空态改为真实数据库查询。验收：创建后在同用户列表可见、刷新不丢失，另一用户无法取得；无数据时显示真实空态而非样例。记录 API 响应与 DB 行。

## T3 数据集导入与校验（依赖 T2）

输入：datasets 快照表、`storage.md`。实现 ZIP 流式上传与配额、路径/链接/炸弹拦截、YOLO 标签与类目/划分校验、报告落盘及任务化验证；界面分步骤显示真实报告。验收 A2：含合法和恶意样本、哈希、目录差异；失败不写库成功态。

## T4 Worker 生命周期与训练（依赖 T3）

输入：jobs 表/状态机、`task_process.py` 明确拒绝的占位。用可配置 runner 注册真实 YOLO11n Ultralytics 训练，输入白名单与环境预检，任务隔离目录，FIFO 单重任务，进程组取消与超时回收；防 stdout pipe 塞满，状态与产物登记先后顺序正确。验收 A3/A4：两个任务串行、小样本 CPU 1 epoch 实训、取消/重启故障注入；输出真实权重哈希和日志。

## T5 日志、指标和实验对比（依赖 T4）

输入：job_events/metrics 表与 SSE 契约。将真实训练输出结构化持久化，按 seq 回放、断线续订、GET 快照恢复；比较仅同任务类型/明确数据快照的实验，标注不同数据不可直接比较。验收 A5：重连无重复指标、终态一致；提供原始日志与曲线数据，不用计时器合成。

## T6 模型元数据与安全下载（依赖 T4）

输入：artifacts 表、`model-metadata.md`。登记 best/last、来源链、类目/输入/预处理/框架版本、SHA-256 和校验状态；按资源 ID 权限下载；任意上传 PT 暂不开放。验收：文件哈希不一致阻断下载、跨用户不可读、失败任务无可用模型。

## T7 ONNX 导出验证（依赖 T6）

输入：`export_onnx` job、固定 PT 和单图样本。执行导出→ORT CPU 真实载入→shape/输出解析→预设容差比较→证据落盘；完成后才显示 validated。验收 A6：成功样本、无效 ONNX、输出偏差、取消；RKNN 仅 adapter interface 报 UNSUPPORTED_TARGET，不暴露完成按钮。

## T8 单图真实推理（依赖 T7）

输入：验证过的 ONNX artifact、受限图片、阈值。封装一致预处理/后处理、保存检测 JSON/可视化和输入哈希，前端显示真实框。验收 A7：重复样本/阈值变化可解释，畸形图片失败，不可伪造检测结果。

## T9 部署 ZIP 与复现（依赖 T8）

输入：已验证 ONNX、同版预处理元数据与示例图。生成清单和 Python ONNX Runtime 示例，签出 ZIP 哈希；在干净目录解包后重跑实际推理。验收 A8：包内无用户私密路径/数据库/临时文件，结果可复现，下载鉴权正确。

## 每项交付模板

任务 ID/基线 commit；代码/迁移/TS 契约变更；权限与失败分支；实际命令与退出码；输入/产物 SHA-256；通过/失败/未执行；证据路径；剩余风险。禁止在 T1–T9 的实现提交中把未做完的下一项顺手标成已通过。
