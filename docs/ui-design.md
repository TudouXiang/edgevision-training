# 正式前端重设计（2026-09-23）

以 `ui-ux-pro-max` 的操作台密度/状态区分与 `apple-design` 的响应、节制动效、空间连续性和系统字体原则为参考；既有 Next.js 页面保留原始源码。设计对象是需要长时间关注训练任务的桌面用户，不使用虚构 KPI 吸引注意力。

## 页面与状态

- 左侧固定工作流导航：工作台、项目、数据集、训练、模型、ONNX、推理、部署；管理员页待账号 API 完成后按真实角色出现。
- 工作台概览只显示 API 健康/迁移就绪和各功能能力开关；业务数量在无真实列表接口前显示 `—` / `待接入`，不显示零或随机增长的数。
- 未实现页保留真实入口位置、工作要求、所依赖的上游步骤与禁用的主要操作。登录未实现时，明确显示“尚未登录 / 尚未接入”，不提供角色切换或伪身份。
- 网络请求含加载/断线/就绪失败态及可重试按钮，未实现操作保持禁用；所有状态以文字说明，颜色只作辅助。
- 管理员信息架构在 T1 后接入：全局概览、用户管理、项目与任务审查、存储与失败日志。没有真实管理员会话前不展示角色切换或虚构“全平台运行任务”；通用组件复用同一设计令牌。

## 视觉与交互令牌

主视图暖浅灰背景、白色功能面板、深墨色侧栏，松石绿只标示可执行的主路径，琥珀色提示待办，蓝灰文字承载长时间阅读。用系统中文无衬线字体与等宽数字；8px 节奏，最大内容宽度约 1240px。透光效果只用于浮动顶栏，不叠加玻璃卡片。导航/面板反馈约 160ms，禁止循环假进度；减少动态效果时只保留颜色/静态状态变化。

键盘可到达导航、刷新与返回；焦点可见，侧栏小屏可关闭；布局支持 375/768/1024/1440px。接入真实项目/训练后再做数据表、SSE 指标图、真正的创建表单，不能提前展示“训练完成”。前端源码见 `web/`。
