# ADR 0002：保留演示前端并隔离正式入口

状态：已接受，2026-09-23。

既有 `reference/edgevision-studio-frontend.zip` 是 Next.js/Vinext Sites 演示源码，不是已验收平台。它包含硬编码统计、循环训练日志、计时转换成功以及 Redis/Celery 设备监控，与单机基线冲突。保留原件，正式骨架新建 Vue3/TypeScript 界面与真实状态边界；后续仅在对应真实接口完成后逐页复用其视觉与交互设计。

影响：临时有演示原型与正式最小界面两份源码，演示原型不能公开为业务运行版。最小调整优于在演示源码内逐项排查所有虚构路径且继续保留 Cloudflare/D1 前置条件；完全删除会丢失已有设计资产。若后续用户要求 Next.js 作为最终技术栈，须先重新审视部署/身份/D1/本地 Worker 边界并修改本 ADR。
