# 演示与论文证据提纲（待最终验收）

这是一份可执行的准备提纲，不是已完成演示记录或论文实验结果。
当前范围以 [交付闸门](../evidence/T070-delivery-gates-2026-11-15.md) 为准。
正式题名、学校模板和答辩硬性要求尚未提供，不作假定。

## 演示顺序与失败出口

1. **启动与登录**：按仓库 README 启动独立数据目录中的 API、Worker、Web；
   管理员在本机交互初始化，不将密码写入文档或录像。先确认健康状态和实际能力。
2. **项目与数据**：创建演示项目，上传具有许可且已冻结划分的数据集，查看校验结果。
   对校验失败展示明确原因，不把失败数据投入训练；不使用个人或公司私有资料。
3. **受管训练**：只有当前环境能力门禁通过时才提交固定适配器训练；展示排队、进度、
   日志和产物追溯。轻量安装不具备 ML 能力时，说明限制并展示对应历史 CI 证据，
   不用录屏或测试替身冒充当前机器执行。
4. **结果对比**：选择实际成功任务，解释同数据版本、相同指标口径的重要性。
   一轮烟测证明流程可运行，不证明模型已充分收敛。
5. **导出与推理**：展示严格导出校验。真实 Oxford 子集目前有数值容差失败，
   应展示被拒绝及失败原因，不下载或演示一个未验收的产物。已有固定工程烟测
   的 E/I/P 证据单独标明来源，不能拼接成该真实数据模型的成功链路。
6. **独立交付**：仅对通过门禁的模型生成源码包，说明包不含 Python 或依赖 wheels，
   默认安装仍需可用依赖源，不宣传“完全离线即用”。离开平台环境的独立验证
   以对应精确包的证据为准。
7. **可靠性**：说明任务取消、受管 Worker 中断恢复、静默备份/恢复的受控演练，
   不在用户正在使用的数据目录模拟破坏或整机掉电。

## 不可填充为“实验结果”的空白

- 目前没有该真实数据模型的合格 ONNX 产物，不能填写 PT/ONNX 正式精度或延迟对比。
- 一轮训练指标不能冒充独立测试集 mAP；训练/验证/测试角色不能互换。
- 不能由 CPU 烟测推断 XiaoHu CUDA、Windows ML、RKNN 或实机 NPU 性能。
- 正式性能实验应先冻结设备、线程、输入、预处理、NMS、warm-up、计时分段、
  重复次数和统计口径，再执行并保存实际数据；本提纲不预设任何虚构数字。
