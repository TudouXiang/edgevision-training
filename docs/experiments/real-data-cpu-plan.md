# 最小真实数据 CPU 实验计划（未执行）

目的：验证平台在真实标注数据上的可复现训练、PT/ONNX 一致性与有限 CPU 性能，不追求大规模模型精度结论。此计划不代表数据已下载、训练已运行或正式学校题名已确认。

## 候选数据与发布边界

候选 [Oxford-IIIT Pet 官方数据](https://www.robots.ox.ac.uk/~vgg/data/pets/)，官方标示 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。网页现行CC BY-SA与下载包README旧research-only说明并存；本任务限定非商业本科研究，保留两份原说明，图片和改编数据不公开分发，不声称商业权利已清理。使用前保存当次官方许可说明、原归档hash和实际标注核验；图片权利仍归原权利人，不据公开下载推断拥有全部版权。公开仓库仅保存转换规则、来源、许可及脱敏摘要，不上传原图、转换数据或训练模型。若分发改编数据须保留署名、修改说明与相同许可。Penn-Fudan 因未找到明确许可暂不使用。

真实标注是头部框，不是全身框；两个类别固定为 `cat_head`、`dog_head`。若官方标注不足、许可变化或数据下载校验失败，停止，不改用伪造图片/框。

## 在看模型结果前冻结的选择规则

- 先核对官方 trainval/test 清单、species 和 XML；只取实际图像及XML中恰有一个有效头部框、尺寸匹配且图像hash不重复的样本。
- 框采用原始XML坐标规范，转换前须以官方格式说明及实际样例核对1-based/inclusive约定；此项未核实前不冻结转换产物、不训练。不用“自动夹紧”掩盖坏框。
- 排序键为 SHA256(`edgevision-real-cpu-v1:` + 原文件名)。每类仅从官方 trainval 有有效XML的集合依序取30训练、接下来的10验证、再10测试，共60/20/20；三者互斥，这是自定义重划分而不是官方test成绩。此前候选采用官方test的方案已在任何图像下载/训练前否决，因为实际归档test没有XML，不能以空标签代替。
- 对三个划分按原文件名与图像hash交叉检查无交集。记录每张原图/XML/转换标签hash、原归档hash、选择规则版本、类别和划分。先存manifest及总hash，再训练；不按结果重选样本。
- 这是自定义有限子集，不能称Oxford官方基准成绩。若某类有效数不足则停止并修订计划后重冻，不事后凑数。

## 预算与口径

- 在有资源的 Linux x86_64/CPython3.12 CPU 隔离环境，使用现有可信YOLO11n及当前源码绑定probe。不得在swap压力大的用户工作机强行运行。
- 一次训练：epochs=1、imgsz=320、batch=1、seed=0、learning_rate=0.01；全局单重任务。最多10分钟训练预算，超限记录失败，不无界重试/调参。
- 指标来源：训练验证指标只叫验证指标；只有在冻结测试集上独立执行得到的结果才叫测试集指标。有限1epoch不是模型能力达标承诺，不设事后精度阈值。
- 训练imgsz=320；PT/ONNX对照推理固定遵循现有640×640协议，不把训练尺寸当导出或推理尺寸。PT与ONNX必须使用同一测试输入、类别、letterbox/归一化、阈值、NMS设置。先核对平台冻结算法的实际参数并记入manifest；不直接比较两个不同后处理实现的耗时或框数。
- 每后端只加载模型一次，加载耗时单独记录，不计稳定推理。每后端用测试列表首图预热5次（不计样本）；随后按冻结顺序处理20张测试图一次，共20次测量/后端，不是每图20次。CPU线程固定2，batch=1。
- 纯推理测量：图像字节预读到内存，计时从图像解码开始，到后处理结果就绪结束；不含模型加载、磁盘读取/写入和HTTP排队。分段记录解码/预处理、模型执行、后处理。完整HTTP另测同样20图：从发送请求到收到终态和结果，明确含上传、排队及服务端存储；不得把此值写成模型耗时。若不能可靠取得某分段，就标NOT_RUN，不由总值猜测。
- 单位毫秒；保存逐次原始值。中位数为排序后第10与11项均值，p95使用nearest-rank（20项取第19项）。不得按后端改变口径或剔除慢样本；超时和失败逐项保留。
- PT/ONNX一致性沿用已冻结工程验证阈值，保留原值与失败；不能为“通过”放宽阈值。准确率/吞吐结果没有运行证据时写 NOT_RUN。

## 隔离执行协议冻结（运行前）

独立 `run_real_cpu` 手动开关，不与旧 `run_isolated_ml` 同选。明确绑定完整提交 SHA；默认 push/PR 不运行模型。沿用禁网、非 root、cap-drop ALL、无宿主挂载、6 GiB / 2 CPU 隔离边界。准备阶段仅下载固定公共归档及官方基础模型；不上传镜像/缓存/日志/图片/预测数组/模型。新容器执行最多1500秒，内部业务链1440秒，工作流45分钟含准备和构建；旧十二阶段与480秒上限不变。

测试精度采用冻结的单头框协议 `single-head-p025-iou050-v1`：confidence > 0.25、NMS IoU 0.45、匹配 IoU >= 0.5，每图一个标注最多匹配一个TP，多余预测计FP。公布20图的TP/FP/FN、precision/recall；无预测时precision约定为0。这不是mAP，不是官方Oxford基准。PT/ONNX原始输出继续采用 atol=rtol=1e-4，检测匹配沿用现有算法，不因真实图片而放宽。

模型加载时延单独记录；稳定样本从预读编码图片的内存解码开始，不含磁盘读取、模型加载和预热。HTTP时延另含上传、排队、Worker启动、存储和读取结果，不等同纯模型推理性能。

故障演练是两项独立任务，各配置最多2 epochs，仅用于在第一轮真实有效metric事件（核对job/run）出现后立即取消或杀掉所属Worker；它们不提供精度结果，也不是主实验重跑。原主实验仍固定1 epoch。每项等待真实metric最多180秒，未就绪则失败，不用空日志文件冒充模型已执行。所有任务需验证完整树drain receipt；异常清理证据不足记录unverified，最终仍由外层销毁所属容器，不宣称已完成。

恢复演练保留产品权限：`inference_input`下载应为409，不能为验收修改成200；其字节由停写后的全文件hash恢复校验覆盖，可下载产物核对200/长度/hash。恢复至全新私有目录，原会话与元数据读取校验不代表新主机原生能力已验收。

预检发现 `.12g` YOLO标签转换回像素时一个零边界为 -1.875e-10 像素。由于源VOC为整数坐标，评价阶段仅在每坐标距整数<=1e-6像素且整数框严格在图内时恢复原整数，不夹紧任意坏框。20个冻结测试框已实际通过此验证；平台自身数据验证器也已验证100图/100标注（60/20/20），这些都不是模型结果。
